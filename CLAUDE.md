# job-search-agent — start here

This repo has two unrelated parts:

- **The real, day-to-day job-search workflow** — an interactive,
  skill-driven process. For any task involving finding, evaluating,
  drafting, or submitting a job application, read `soul.md` first,
  then follow `skills/job-search/SKILL.md` — it sequences every other
  piece (profile, cv-tailoring, senior-it-recruiter, submission,
  record-keeping) in the right order.
- **`src/`, `tests/`, `bin/`** — a separate PHP portfolio prototype
  (an Anthropic tool-calling agent loop). It does not drive the real
  workflow above — see `README.md` for its actual state. Don't assume
  it describes how applications actually get made.
